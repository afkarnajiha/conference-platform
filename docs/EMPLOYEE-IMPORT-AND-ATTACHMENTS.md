# تحديث استيراد الموظفين وإصلاح اختيار المرفقات

مخصص لنسخة التسجيل المباشر دون مراجعة أو حجز. لا يتطلب SQL جديدًا أو تغيير مفاتيح أو إعادة نشر Edge Function؛ يستخدم وظيفة `manage-account` الموجودة لإنشاء الحسابات.

## التثبيت

1. احفظ نسخة من مشروعك أو اعمل Commit قبل الاستبدال.
2. انسخ محتويات الحزمة إلى جذر مشروعك الحالي بجانب package.json، وادمج المجلدات ووافق على استبدال الملفات المتطابقة. لا تحذف أي مجلد. إذا خصصت pages.tsx أو visits.tsx فراجع فروق الملف قبل الاستبدال للحفاظ على تخصيصاتك.
3. نفذ `npm.cmd test` ثم `npm.cmd run build`.
4. اعمل Commit ثم Push وانتظر نجاح GitHub Actions، ثم حدث الموقع بـ Ctrl+Shift+R.

## استيراد الموظفين

1. ادخل بحساب المدير وافتح «فريق العمل» ثم «استيراد Excel».
2. اختر ملف XLSX الخاص بك. تُقرأ ورقة «بيانات الموظفين» فقط إذا وجدت، وإلا الورقة الأولى. لا تُرفع نسخة الملف إلى الخادم ولا تُرسل الأوراق الأخرى.
3. تظهر معاينة الاسم والبريد والمسمى الوظيفي، والبريد غير الصحيح والمكرر والحسابات الموجودة. المسمى الفارغ يبقى فارغًا.
4. راجع القائمة ثم فعّل مربع الموافقة واضغط «إنشاء الحسابات وإرسال الدعوات». الحسابات الجديدة تكون موظفين فقط ولا تستبدل حسابات موجودة.
5. التنفيذ متتابع ويتوقف عند أول فشل، وتبقى الحسابات الناجحة. زر الإيقاف يوقف الدفعة بعد الحساب الجاري، ولا يلغي الحسابات المنشأة.
6. إذا توقف الإرسال بسبب SMTP أو حدود البريد، عالج إعداد البريد أولًا. حدّث قائمة الفريق وأعد اختيار الملف لإعادة فحص الحسابات الموجودة. لا تعِد الطلب بلا تحقق إذا كانت نتيجة الحساب الأخير غير معروفة بسبب انقطاع الاتصال.

يتطلب الاستيراد صلاحية المدير أو مشرفًا مُنح إدارة الموظفين. صلاحيات الخادم الأصلية مستمرة. لا تنفذ هذه الحزمة أي إرسال تلقائي؛ إنشاء الحسابات وإرسال الدعوات يحدثان عند تأكيد المستخدم داخل الموقع فقط.

## إصلاح المرفقات

الخلل المؤكد: كانت الدالة تحتفظ بمرجع FileList الخاص بعنصر اختيار الملفات، ثم تنتظر فحص الملفات. في هذه الأثناء كان عنصر الاختيار يُمسح، فتفرغ القائمة قبل إنشاء معاينة المرفقات. الإصلاح ينسخ الملفات إلى مصفوفة مستقلة قبل أي انتظار، ويمنع حفظ النموذج أثناء فحص الاختيار.

بعد التحديث افتح زيارة جديدة واختر صورة JPG أو PNG أو WebP أو PDF أقل من 10MB. يجب ظهور بطاقة تحمل اسم الملف قبل الضغط على حفظ. احفظ الزيارة ثم تحقق من وجود المرفق وافتحه. مجرد اختيار الملف لا يرفعه إلى السحابة؛ الرفع عند حفظ الزيارة.

إذا ظهرت البطاقة ثم فشل الحفظ، فهذا خطأ مختلف يحتاج Response لطلب Storage. لم تُختبر حاوية Supabase الحية من هذه المحادثة. لا تجعل الحاوية عامة ولا تعطّل RLS لمعالجة الخطأ.

## محتويات الحزمة

- src/employee-import.ts وsrc/EmployeeImport.tsx: قراءة الملف والمعاينة والاستيراد.
- src/pages.tsx: زر الاستيراد في صفحة الفريق، مع الحفاظ على التسجيل المباشر.
- src/attachment-selection.ts وsrc/visits.tsx: إصلاح اختيار المرفقات.
- tests: فحوص التكرار وتطابق الأعمدة، وعدم الإرسال قبل التأكيد والتوقف عند الخطأ، واختبار انفراغ FileList أثناء الفحص.

ملف بيانات الموظفين الشخصي غير موجود في الحزمة، ولا توجد أسماء أو عناوين بريد حقيقية في المصدر أو الاختبارات.
