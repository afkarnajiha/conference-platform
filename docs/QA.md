# سجل التحقق — 7 نوفمبر 2026

## نُفّذ محليًا

- بناء TypeScript وVite للإنتاج بنجاح.
- 29 اختبارًا لقواعد الإدخال والتوقيت والملفات وCSV، وتفاعل الواجهة، وقراءة ملف XLSX مولّد فعليًا.
- 38 فحصًا لملفات SQL عبر PGlite، مع إنشاء أدوار auth وstorage لاختبار السياسات محليًا.
- فحوص قاعدة البيانات تشمل: RLS، منع وصول الزائر والحساب المعطّل، منع التصعيد الوظيفي، صاحب الحجز، انتهاء الحجز، منع تكرار الجولة، الزيارة الإضافية، مراجعة المعرض، التوزيع، حماية آخر مدير، توقيت وهوية الخادم، ومنع قراءة المرفق قبل الحفظ ومنع حذفه بعده.
- اختبارات التفاعل تشمل: البحث والفرز والتقسيم والتصفية، تعديل المعرض، إعادة التعيين، التوزيع، إنشاء وتعطيل الحساب، حساب المؤشرات، متابعة الفرص، الدخول والخروج، إخفاء وظائف الإدارة عن الموظف، مسار QR المعروف والجديد، رسالة التكرار، حفظ النموذج، ومنع تعديل زيارة الزميل.
- معاينة شاشة الإعداد المحلية في المتصفح عند 1440×1000 و390×844، والتحقق من حدود التخطيط وفتح تعليمات الربط. لم تتوفر جلسة Supabase لمعاينة الصفحات المحمية ببيانات حية.

**حدود هذه النتائج:** اختبارات التفاعل تستخدم بدائل اختبار لطبقة الخدمات؛ لا تثبت نجاح البريد أو Auth الحقيقي. PGlite يشغّل الاستعلامات تسلسليًا؛ لا يثبت سلوك اتصالين متزامنين. بيانات الاختبار معزولة في `tests` ولا تُحمّل إلى التطبيق أو إلى أي قاعدة بيانات للشركة.

| الاختبار | معيار النجاح |
| --- | --- |
| الدخول والخروج والاستعادة والدعوة | نجاح البريد والجلسة وإعداد كلمة المرور بحسابات المشروع الحقيقي |
| الأدوار الثلاثة | منع الاستدعاءات غير المصرح بها عبر REST مباشرة، وليس الواجهة فقط |

| كاميرا الجوال | القراءة على Android وiPhone عبر HTTPS، ومعالجة رفض الإذن |
| تنوع QR | رابط موقع وPDF ونص ومعرف، وعدم فتح الرابط بوصفه زيارة |

| الهاتف والتابلت والكمبيوتر | مراجعة جميع الصفحات المحمية بعد الربط، وليس شاشة الإعداد فقط |
| GitHub Pages | نجاح Workflow وbase path وتحديث جميع مسارات hash |

## إجراءات التشغيل

لا توجد نتيجة نجاح مزعومة لاختبارات القبول أعلاه. يجب إكمالها بعد الربط وقبل استخدام بيانات الشركة الفعلية. إذا استُخدم مشروع اختبار، استخدم بيانات واضحة أنها للاختبار ولا تنقلها إلى الإنتاج.
