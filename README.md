# منصة الأفكار الناجحة التجارية

منصة عربية RTL لإدارة مشاركة فريق الشركة في المؤتمرات والمعارض، باستخدام React وVite وTypeScript وTailwind وSupabase. الاستضافة المستهدفة GitHub Pages فقط، مع المصادقة والبيانات والتخزين ووظيفة إدارة الحسابات في Supabase.

**الحالة الحالية:** المشروع مُنفذ محليًا. لم يُرفع إلى GitHub ولم يُربط بمشروع Supabase بناءً على طلب صاحب المشروع. تظهر شاشة إعداد واضحة حتى إضافة إعدادات الاتصال، ولا تُعرض بيانات وهمية. نجاح الاختبارات المحلية لا يعني أن خدمات السحابة اختُبرت.

## التشغيل المحلي

المتطلبات: Node.js إصدار 22.12 أو أحدث، وnpm. افتح الطرفية داخل هذا المجلد:

```sh
npm ci
npm run dev
```

دون ملف `.env` تظهر شاشة الإعداد فقط. بعد الربط، تنسخ `.env.example` إلى `.env` وتدخل رابط المشروع والمفتاح العام. أعد تشغيل Vite بعد تغيير البيئة.

```sh
npm test
npm run test:db
npm run build
npm run preview
```

إذا منعت بيئة Windows المقيدة esbuild من قراءة مجلدات أصلية، يمكن استخدام `npm run build` ثم `npm run preview`؛ البناء والمعاينة يستخدمان `--configLoader runner`.

## الوظائف الموجودة في المصدر

- الدخول والخروج واستعادة كلمة المرور وتعيينها بعد الدعوة، مع حراسة الصفحات حسب الدور.
- مدير ومشرف وموظف، وRLS على جميع جداول التطبيق. صلاحية إدارة الموظفين تمنح للمشرف صراحةً.
- إنشاء المؤتمرات وتعديلها وتوزيع الفريق على التواريخ من الأحد إلى الأربعاء.
- قارئ كاميرا QR للأكواد الأصلية، وإدخال نص أو رابط يدويًا، وإنشاء سجل قيد المراجعة أو ربط رمز بمعرض موجود بواسطة المشرف.
- حجز لمدة 20 دقيقة داخل PostgreSQL، ومنع التكرار بقفل صف وقيد فريد. تحرير الحجز، وسماح المدير بزيارة إضافية مع سبب وسجل تدقيق.
- نموذج الزيارة والتقييم والتواصل والفرص والمرفقات. اسم الموظف وتوقيت الزيارة من الخادم.
- ملفات خاصة متعددة، ومعاينة الصور أو PDF وإزالة الملفات قبل الحفظ؛ روابط قراءة موقعة لمدة دقيقة.
- لوحات الموظفين والإدارة، وإحصاءات ورسوم من البيانات، وRealtime مع تحديث احتياطي كل 30 ثانية.
- إدارة الفريق بواسطة Edge Function، وتعديل الحساب وتعطيله واستعادة كلمة المرور وحذفه إذا لم يرتبط بسجلات. الحساب المرتبط بسجلات يُعطّل حفاظًا على التاريخ.
- مراجعة الزيارات وتعديلها وفق الصلاحية، وإدارة حالة متابعة الفرص التجارية.
- جداول بالبحث والفرز والتصفية وتقسيم الصفحات. تقارير الزيارات والمعارض والفرص والأولوية المرتفعة والملخص النهائي.
- Excel XLSX عربي RTL، وCSV بترميز UTF-8 BOM مع حماية من حقن صيغ الجداول، وطباعة عربية كاملة مع خيار حفظ PDF من المتصفح.
- ملف GitHub Actions للنشر التلقائي وHashRouter لعمل الروابط عند تحديث الصفحة.

## ترتيب المرحلة التالية

1. رفع **محتويات هذا المجلد** إلى جذر مستودع GitHub، لا المجلد الأب `outputs`.
2. إنشاء مشروع Supabase وتطبيق الترحيلات وإعداد المصادقة والتخزين ووظيفة إدارة الحسابات وفق [دليل الربط](docs/DEPLOYMENT.md).
3. إضافة متغيرات البيئة إلى GitHub وإعادة البناء والنشر.
4. تنفيذ اختبارات القبول الحية قبل اعتماد المنصة للشركة.

## حدود تشغيلية واضحة

- اختبار المصادقة والبريد وStorage وRealtime فعليًا ينتظر ربط Supabase.
- قارئ الكاميرا يحتاج HTTPS وإذن المستخدم؛ لم يُختبر على كاميرا هاتف فعلية في هذه المرحلة.
- PDF يُحفظ من نافذة الطباعة؛ لا يوجد مولد PDF سحابي أو خدمة مدفوعة.
- لا تُحفظ بيانات النماذج الحساسة في localStorage؛ إغلاق النموذج قبل حفظه يفقد مسودته، وينتهي حجزه تلقائيًا بعد المهلة.
- المرفقات غير المعتمدة قد تبقى إذا انقطع الاتصال أثناء الرفع. يمكن تنظيفها دوريًا عبر Storage API بعد التحقق من عدم ارتباطها بزيارة. لا تحذف صفوف `storage.objects` مباشرةً في الإنتاج.
- فحص الملفات يشمل التوقيع المحلي وMIME والحجم وسياسات الوصول، وليس فحصًا بمضاد فيروسات. حد 10 ملفات و10MB للملف؛ محتوى QR حتى 2000 بايت.
- بيانات الشركة متاحة للحسابات النشطة وفق المتطلبات، وليست المنصة خدمة متعددة الشركات.
- التقارير تحمل السجلات المصرح بها على دفعات؛ للمؤتمرات الضخمة جدًا يُفضّل لاحقًا نقل التجميع والترشيح إلى استعلامات خادم مخصصة.
